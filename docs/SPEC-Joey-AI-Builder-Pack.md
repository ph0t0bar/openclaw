# Joey AI Builder Pack — Product Spec

**Source:** Joey's drop, March 15, 2026
**Status:** Post-launch (Week 3-4 target)
**Relationship to PRD:** This IS the Advisory Mode tier ($49-149/mo per seat) from Section 4's revenue flywheel, productized as a 7-day onboarding sprint.

## Connection to Existing Stack

| Builder Pack Component | Already Built As |
|----------------------|-----------------|
| Context Ingestion | DropAnywhere multi-channel capture (7 channels live) |
| Org Brain | Hub Intelligence Map + drop classification |
| Weekly Outputs | Snapback / Weekly Catch (catch_router + snapback_generator) |
| Communication Style | Language fingerprint extraction (snapback_generator.py) |
| Recurring Rituals | Daily digest + Weekly Catch + email prompts |
| AI Execution | Hub DCS Protocol + Poe Orchestrator |

## What's New (Not Yet Built)
- Slack/Notion/Jira ingestion connectors (currently: email, SMS, voice, web, Chrome, iOS, Poe, BHA)
- Graph-based Org Brain (currently: flat vault + Intelligence Map)
- /joey slash commands for Slack
- Team-level context (currently: individual user)
- "Done work" generation (project plans, board updates, customer emails)

## Revenue Model
- 7-day Builder Pack: $1,000-2,000 (service-wrapped software)
- Ongoing: $49-149/mo per seat (Advisory Mode from PRD)
- Target: 5 customers at $1.5K = $7,500 in first 4-6 weeks post-launch

## ICP v1
2-20 person AI/tech startup, $0-$2M ARR, founder is the bottleneck.

## Key Insight
"Unlike horizontal AI copilots that know 'general work,' Joey builds a private Org Brain from your own Slack, docs, and tickets in 24 hours — and uses it to ship context-aware work that sounds like you and fits your processes."
