## 3. The Joey Content Workflow (Detailed)

### Phase 1: Capture (The Drop)

**Inputs:**
- Voice memo (iOS Shortcuts → Hub API)
- Screenshot + context (Share sheet → DropAnywhere)
- Email (vault@drop-anywhere.com)
- Web clip (Chrome extension)
- WhatsApp/Telegram message (linked accounts)

**Storage:**
- Raw drops → Vault (JSON + PostgreSQL)
- Metadata: source, timestamp, location, device, screenshot OCR

**Intelligence Extraction:**
- Auto-tagging: topic, sentiment, urgency, content type hint
- Link extraction: URLs mentioned → fetch + summarize
- Entity recognition: people, projects, deadlines

### Phase 2: Processing (The Intelligence Layer)

**BHA Persona Selection:**
```yaml
content_type: "blog_post"
  → persona: "UnderThinker" (strategic analysis)
  → persona: "theREALrealtalk" (voice matching)
  
content_type: "video_script"
  → persona: "GrowthOracle" (engagement optimization)
  → persona: "DecisionMaker" (structure + clarity)
  
content_type: "linkedin_post"
  → persona: "BrutallyHonestAI" (authentic voice)
  → persona: "IdealPrompt" (hook optimization)
```

**Orchestr8 Swarm (Research Phase):**
```
Gemini 2.5 Flash: Trend research, competitor analysis
GPT-4o: Audience pain points, keyword research  
Claude Sonnet: Structure, narrative arc, voice matching
```

**Output Templates:**

#### A. Blog Post Template
```markdown
---
title: "[SEO-optimized title]"
hook: "[Pattern interrupt opening]"
thesis: "[One-sentence argument]"
main_points:
  - "[Point 1 with evidence]"
  - "[Point 2 with story]"
  - "[Point 3 with actionable advice]"
cta: "[Clear next step for reader]"
seo_keywords: ["keyword1", "keyword2"]
---

[Full draft generated by BHA persona]
```

#### B. Video Script Template (Remotion-ready)
```javascript
// Remotion composition structure
const contentBrief = {
  duration: 60, // seconds
  scenes: [
    { time: 0-3, visual: "hook_text", audio: "voiceover_hook" },
    { time: 3-15, visual: "problem_statement", audio: "voiceover_problem" },
    { time: 15-45, visual: "solution_demo", audio: "voiceover_solution" },
    { time: 45-60, visual: "cta_screen", audio: "voiceover_cta" }
  ],
  assets_needed: ["screenshot_1", "screen_recording", "broll_footage"]
};
```

#### C. LinkedIn Carousel Template
```markdown
Slide 1: Hook (contrarian statement)
Slide 2-5: One insight per slide (minimal text)
Slide 6: Proof/example
Slide 7: CTA

Design notes: Brooke theme colors, Newsreader font, liquid glass aesthetic
```

### Phase 3: Production (The Ship)

**Remotion Pipeline:**
1. Export structured JSON from BHA
2. Remotion server renders video
3. Output to S3 → review link
4. Approval → auto-post or schedule

**Static Visuals (Canva):**
1. BHA generates copy + layout suggestions
2. Canva API creates design from template
3. Review → export PNG/PDF

**Video Editing (Descript):**
1. Transcribe raw footage
2. BHA suggests cuts based on "um" detection + content value
3. Auto-generate captions (Brooke theme styling)
4. Export for platforms

**Publishing Workflow:**
```
Drop: "Publish [content] to [platform]"
  ↓
OpenClaw receives
  ↓
Create task for: copy formatting, scheduling, cross-posting
  ↓
Confirm: "Posted to LinkedIn, Twitter, Instagram. Links: [x], [y], [z]"
```

## 5. Automation Opportunities

### iOS Shortcut: "Create Content"
```
Trigger: Share sheet (text, URL, image)
Action 1: Send to Hub API (source: shortcut)
Action 2: Classify content type (use BHA Reflex)
Action 3: Route to appropriate persona queue
Action 4: Notification: "Drop received. Processing with [persona]."
```

### Dropper-Code Task: Content Template Generator
```yaml
title: "Generate content templates from vault drops"
trigger: daily at 6am
action:
  - Search vault for drops tagged "content-idea"
  - Generate 3 templates per idea (blog, video, carousel)
  - Store in `content-pipeline/` folder
  - Notify Joey with summary
```

### OpenClaw Heartbeat: Content Pipeline Check
```
Every 6 hours:
  1. Check vault for "content-idea" drops > 48h old without output
  2. Flag for follow-up: "You had an idea 3 days ago — still want to make it?"
  3. Surface stuck items in morning brief
```
