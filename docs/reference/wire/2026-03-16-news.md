### Key Finding: Anthropic's Three-Layer Memory Architecture

**Launch Details:**
- **Date:** March 2, 2026 — rolled out to ALL users including free tier
- **Core tech:** "Memory Synthesis" auto-distills long-term details (profession, preferences, tools) every ~24 hours
- **What it is:** Persistent recall across chat sessions, NOT full RAG

**Three-Layer Architecture:**
| Layer | Target | What It Does |
|-------|--------|--------------|
| **Chat Memory** | All web/desktop users | Auto-summarizes "worth remembering" info; manage via "Remember X"/"Forget Y" commands |
| **CLAUDE.md + Auto Memory** | Claude Code users | Auto-generates MEMORY.md from interactions; loads first 200 lines per session |
| **API Memory Tool** | API builders | Programmable memory handling for custom apps |
