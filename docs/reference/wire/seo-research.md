## 3. Competitive SEO Analysis

### Saner.AI (Direct Competitor)
**Positioning:** AI-native, ADHD-friendly, inbox consolidation
**Keywords:** "AI second brain," "ADHD productivity," "automatic task automation"
**Differentiation:** AI inbox, semantic search, task automation from notes
**Strengths:** Product Hunt launch (4.8/5), AI-first positioning
**Weaknesses:** Narrow focus on ADHD community

### Mem.ai
**Positioning:** Self-organizing workspace, no folders needed
**Keywords:** "auto-organization," "Mem Chat," "smart search"
**Differentiation:** Natural language querying, calendar integration for meetings
**Strengths:** Clean UI, viral in productivity community
**Weaknesses:** Less emphasis on daily digest specifically

### Notion AI
**Positioning:** All-in-one workspace with AI features
**Keywords:** "Notion AI" (110K/mo), "how to use Notion AI" (590/mo)
**Differentiation:** Flexible databases, structured data, massive ecosystem
**Strengths:** Brand recognition, template marketplace
**Weaknesses:** Requires manual setup, not purpose-built for daily digest

### Obsidian
**Positioning:** Privacy-first, local storage, knowledge graph
**Keywords:** "private note taking," "local-first notes," "knowledge graph"
**Differentiation:** Data ownership, graph view, plugin ecosystem
**Strengths:** Developer/power user community
**Weaknesses:** Steep learning curve, minimal AI native features
