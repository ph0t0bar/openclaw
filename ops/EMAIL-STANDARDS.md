# Email Standards — ALL AGENTS MUST FOLLOW

## Single Sender Identity

**ALL emails from the company use:**
- From: `DropAnywhere <hello@drop-anywhere.com>`
- Reply-To: `hello@drop-anywhere.com`

**NEVER use:**
- noreply@drop-anywhere.com
- joey@drop-anywhere.com  
- Any other from address

**Why:** Joey's inbox = one conversation with one entity. Multiple from addresses = chaos.

## Subject Line Prefixes (mandatory)

| Stream | Prefix | Example |
|--------|--------|---------|
| Morning Brief | ☀️ | ☀️ Morning Brief — Mar 17 |
| Creative Review | 🦜 | 🦜 Creative Review — 3 items |
| Task Approvals | ⚙️ | ⚙️ 2 tasks need your call |
| Alerts | 🚨 | 🚨 Poe balance critical |
| Weekly Report | 📊 | 📊 Week in Review — Mar 10-16 |
| Claw Conversation | 💬 | 💬 Claw — Re: MEGA campaign |
| One-pagers/Docs | 📄 | 📄 Get Started — PDF attached |

## Template Rules
- Brooke theme ALWAYS (cream #FDFBF7, copper #C17F59, sage #5B7B6A)
- Footer ALWAYS: "Reply to this email — Claw reads every reply. 🦜"
- No raw HTML tables — use styled divs
- Mobile-first (max-width: 700px)
